# Mockup de paginación del historial

La página `historial.html` muestra con datos ficticios la primera página, una página siguiente y el error con reintento. La ficha permanece visible. Los ejemplos de filas son ilustrativos: la aplicación mostrará hasta 20 por página. Se basa en el sistema visual revisión 2 y los estilos actuales de fichas.

Abrir `historial.html` en el navegador o revisar `previews/mobile.png` y `previews/desktop.png`.
