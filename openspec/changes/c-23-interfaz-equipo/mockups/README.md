# Maquetas del panel de equipo

Abrir `panel.html` y utilizar la navegación para cambiar entre las nueve vistas. Los nombres, valores y registros son ficticios; controles de formularios y acciones son ilustrativos. La maqueta representa administrador; los enlaces reales dependerán del rol. En Mi cuenta, Volver propone regresar a la pantalla interna anterior o al inicio del rol si se abrió directamente.

Las capturas de `previews/` muestran cada vista en 390 × 844 y 1440 × 900. Incluyen estados representativos; la implementación conservará también carga, vacío, error, operaciones y estados existentes.

Fuente visual: sistema aprobado revisión 2; logo provisional. Approval: approved (2026-11-09, by user).
