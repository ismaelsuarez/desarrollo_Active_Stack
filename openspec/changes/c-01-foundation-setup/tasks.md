Las tareas marcadas **[Estructural]** solo crean archivos de configuración o de empaquetado (`pyproject.toml`, `.gitignore`, `package.json`, Dockerfiles, el workflow de CI, el README): no contienen código de la aplicación, no tienen un RED significativo y se verifican con el chequeo automático indicado. Todo archivo con código de la aplicación, incluidos `alembic/env.py` y los scripts, nace de una tarea **[TDD]** (regla dura 2). Cada tarea cita el requisito que cubre (`capability › Requirement`).
